# iOS Picture in Picture

The user wants the current movie or episode to continue in the system floating
window when SkyStream goes to the background, with behavior comparable to YouTube.

Use Apple's AVPictureInPictureController with an AVSampleBufferDisplayLayer fed
by the existing VLC decoder's CVPixelBuffers. The same display layer renders the
inline video in a Flutter UiKitView, giving AVKit a real on-screen content source.
Keep VLC's streams, headers, selected audio/subtitles, position and decoder alive
through entry/exit. Do not open a second AVPlayer or reload a source for PiP.

Expose this as an opt-in VlcDarwinRenderer.sampleBuffer; existing texture/native
renderers and all non-iOS defaults remain intact. SkyStream opts into it on iOS.
Use `vlc_player/pip` for iOS, retaining the Android app channel and its behavior.
The channel accepts `enterPip` and `setPipState`; it sends `pipModeChanged` bool.
Native playback delegates directly control VLC, including play, pause and seek.
`enterPip` resolves true only on AVKit didStart, false on rejection/failure/timeout.

Enable background audio in Info.plist. Auto-PiP applies only to the active video
player, and respects the OS auto-PiP setting. When PiP is unavailable or fails,
ordinary backgrounding still pauses; foreground resumes only a policy pause.
Closing the PiP window pauses and must not unexpectedly resume later. Do not
autoplay a manually paused video. Existing interruption/headphone policies remain.
Background continuation for the iOS sample-buffer path is managed natively; the
Dart controller must not race it by pausing before AVKit can start.

Bound native frame delivery (latest frame only); preserve visible video aspect
and exclude decoder padding. Dispose must stop PiP and release delegates, frame
callbacks, observers and timebase without retaining the player. Returning to the
app restores the same Flutter player route. iOS deployment stays 15.6 for app,
13 for plugin with availability guards for APIs introduced in iOS 15.

Verify Dart platform/channel/visibility/rendering/lifecycle contracts and native
policy/frame behavior; build and sign with the existing personal configuration.
Install on the paired iPhone if accessible. Report any physical PiP checks that
cannot be performed; compile success alone is not playback verification.
